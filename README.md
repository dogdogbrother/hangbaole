# 夯榜

基于 Vue 3 和 Vite 的「从夯到拉」排行榜制作工具。准备图片，拖入档位，为喜欢的事物排个名。

## 功能

- 批量上传图片，拖拽跨档移动或调整同档顺序。
- 自定义档位名称、颜色和顺序，支持新增与删除档位。
- 图片重命名、移动、删除与清空。
- 编辑排行榜标题，使用 IndexedDB 自动保存草稿。
- 明亮 / 深色主题切换，自动记住当前浏览器的选择，录制模式沿用所选主题。
- 录制模式：榜单铺满页面宽度，先展示主题与开场白，点击“开始排名”后，当前图片才悬浮在榜单中央；讲解完拖入档位，自动展示下一张。也可点击榜单上的档位名称完成排名，排完后保留最终榜单。
- 联系 / 打赏主播：点击右下角按钮，在气泡中查看微信联系、支付宝和微信打赏二维码；录制时自动隐藏。

## 本地运行

```bash
npm install
npm run dev
```

构建生产版本与预览：

```bash
npm run build
npm run preview
```

## 使用说明

单张图片最多 15 MB，每份榜单最多 150 张图片，支持 1～10 个档位。图片在本地等比压缩至最长边 480 像素，仅用于榜单缩略图。

草稿保存在当前浏览器同一来源的 IndexedDB 中。更换浏览器或网站地址不会共享草稿；清除网站数据或使用无痕模式可能导致草稿丢失。

点击顶部“录制模式”旁的月亮 / 太阳按钮切换明亮或深色主题。所选主题会保存在当前浏览器，下次打开时自动恢复；榜单图片、二维码和档位配色保持原样。

准备好图片后，可在榜单上方填写“录制开场白”；默认留空，留空时仅展示主题标题。点击右上角“录制模式”后，榜单自动占满页面可用宽度，左右只保留窄边距。先讲开场，再点击“开始排名”揭晓第一张待排名图片。待排名区的顺序就是讲解顺序；刷新会恢复开场或已开始的进度。退出后再次进入录制会重新展示开场，已排好的图片保留。无待排名图片时直接显示最终榜单。按 Esc 或将鼠标移到右上角点击“退出录制”，可回到完整编辑界面。拖拽中的 Esc 只取消本次拖拽。

录制时，拖动中的图片由页面直接绘制并跟随鼠标或手指移动，避免录屏漏掉浏览器原生拖拽影像。松开到档位后自动揭晓下一张；在榜单外松开或按 Esc 取消时，图片回到原位。
